Evolução do Projeto

Pesquisa & Levantamento Inicial: Proposta de um banco de dados para reunir análises de resíduos da SmartBio. A avaliação do material revelou dados predominantemente visuais, exigindo uma solução além do simples armazenamento.
Redefinição Estratégica: Reformulação da proposta original para o desenvolvimento de uma Inteligência Artificial capaz de processar imagens e extrair dados específicos para a análise de resíduos orgânicos.
Desenvolvimento da Plataforma: Criação da interface visual focada em usabilidade e organização, adequando a plataforma aos requisitos funcionais e facilitando a interação entre homem e máquina.
Expansão de Funcionalidades: Implementação de área dedicada às parcerias institucionais (PROCRIU, CESAR.), ampliando o valor social do sistema e conectando a tecnologia com comunidades reais.
